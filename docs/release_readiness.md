# Release readiness

Version: v0.1.0-preview. This assessment is based on the repository commit recorded in `metadata/release_manifest.json`.

## Ready uses

- Public preview: ready.
- Offline reconstruction: ready.
- Provenance traceability: ready (918 processed non-empty values and 918 lineage records in strict bijection).
- Paper calibration disclosure: ready with screening/comparability limitations disclosed.

## Not yet ready

Formal licensed release is not ready because repository licensing and OSM-derived-output scope require review. Carbon-quota-dependent model execution is not ready because `carbon_quota` is `not_yet_generated`; no quota is guessed in this repository.

Source verification, data-quality, observation-comparability, third-party attribution, and open-issue audits are linked from the README. The release manifest records hashes and counts for reproducibility.

The separate v0.2 candidate DC location study is exploratory only. Its eight
candidate records remain outside v0.1 processed inputs, and no new OSRM matrix
or v0.2 processed dataset has been generated.
