# Carbon-quota generation protocol

`carbon_quota` is not an observed source value. It must be generated by an external carbon/accounting model; this repository does not run an optimizer and does not invent a quota.

An accepted artifact must identify the dataset commit and processed-manifest hash, external model repository and commit, model/formulation identifier, baseline scenario, solver/version/status, emission definition, `E0` value and unit, quota rule and multiplier, resulting quota and unit, timestamps, generator, and input/output hashes. Values must be finite and non-negative. The schema is [`metadata/carbon_quota_artifact_schema.json`](../metadata/carbon_quota_artifact_schema.json), and validation is offline via `scripts/validate_carbon_quota_artifact.py`.

The external model owner must supply the formula and model definition. Until then, `case_config.json` remains `carbon_quota: not_yet_generated` and model execution depending on a quota is blocked.
